No account. No analytics.

Opul does not require an account and the website does not use analytics, advertising trackers, or cookies.

The app connects to addresses you ask it to download from, along with the services and peers required for those downloads. Guided extraction uses a dedicated WebKit data store on your Mac so website sessions can persist. You can clear that data from Opul's settings.

About once a day, Opul asks GitHub whether a newer version exists. That request identifies only the app and its version; it carries no personal information.

GitHub serves source code, releases, updates, and sponsorship. GitHub's own privacy terms apply when you use those services.
